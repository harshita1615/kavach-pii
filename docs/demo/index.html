Try Kavach

Type or paste a message. Kavach finds Indian personal details, replaces them with placeholders, and puts them back in the reply.

Runs entirely in your browser. Nothing you type is sent, stored or logged: this page is not allowed to make network requests at all. Still, please use made-up values.

Use Kavach for real

      
The same detection rules, in three forms:

      

        

          
Chrome extension

          
Warns before you paste or send personal details on ChatGPT, Claude or Gemini, and masks them.

          
Coming soon to the Chrome Web Store.

        

        

          
Python package

          
Mask prompts before your app calls an LLM and restore the reply.

          
pip install kavach-pii

          
Docs · PyPI

        

        

          
MCP server

          
Lets AI assistants such as Claude Desktop, Claude Code or Cursor work from a redacted copy of a file without seeing the personal data in it.

          
pip install "kavach-pii[mcp]"
